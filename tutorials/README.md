# Tutorials

Small examples that show how to use Planforge from Python and Rust.

- `python/goal_count.ipynb`: a Jupyter notebook implementing the goal-count heuristic in pure Python.
- `rust-goal-count/`: a Rust workspace crate implementing the same heuristic as a `Heuristic`.
- `rust-custom-search/`: an external search-algorithm registration using a
  monomorphized uniform-cost priority policy.
